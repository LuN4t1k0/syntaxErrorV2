<Concepto>
Un error en una celda no es un fracaso: es Excel avisando que algo no se pudo calcular, y el nombre del error dice qué. Saber leerlos te ahorra revisar la fórmula a ciegas.

**#¡DIV/0!: dividir por cero.** La fórmula divide por una celda que vale 0 o está vacía. Pasa, por ejemplo, al calcular un promedio por unidad de un producto que todavía no se vende. `SI.ERROR(fórmula; valor)` muestra otro valor cuando la fórmula da error.

```text
=C2/B2              → #¡DIV/0! si B2 es 0
=SI.ERROR(C2/B2;0)  → 0 en ese caso, y el resultado normal en los demás
```

**#¿NOMBRE?: Excel no reconoce algo.** Una función mal escrita, una función en inglés en una planilla en español (`SUM` en vez de `SUMA`) o un texto sin comillas dentro de la fórmula.

**#N/D: no se encontró.** Lo da `BUSCARV` o `COINCIDIR` cuando el valor buscado no existe en la tabla.

**#¡VALOR!: tipo equivocado.** Una operación con texto donde se esperaba un número, como sumar una celda que dice "sin dato".

**#¡REF!: referencia rota.** La fórmula apuntaba a una celda, fila o columna que se eliminó. Hay que volver a escribir la referencia.

**######: no es un error.** La columna es demasiado angosta para mostrar el número. Basta con ensancharla.

**Usa SI.ERROR con criterio.** Ocultar un error con 0 tiene sentido cuando el 0 es la respuesta correcta (un producto sin ventas tiene 0 de promedio). Si el error viene de una fórmula mal escrita, taparlo esconde el problema.

**Tablas dinámicas.** Cuando necesitas resumir muchos datos por categoría o por mes, en Excel puedes insertar una tabla dinámica: arrastras la categoría a filas y el monto a valores, y Excel arma el resumen que en las lecciones anteriores hiciste con `SUMAR.SI`. Saber hacerlo con fórmulas te ayuda a entender y revisar lo que la tabla dinámica calcula.
</Concepto>

<Debrief>
`=SI.ERROR(C2/B2;0)` rellenada en D2:D5 calcula el ingreso por unidad y muestra 0 para la Webcam, que no tiene ventas. `=SUMA(C2:C5)` corrige el nombre `SUMAS`, que Excel no reconoce. Escribir un 0 a mano en D4 tapa el error hoy, pero cuando la Webcam se venda, esa celda no se va a actualizar.

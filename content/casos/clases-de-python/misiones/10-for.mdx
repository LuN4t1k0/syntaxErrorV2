<Concepto>
`for` recorre una colección y ejecuta un bloque una vez por cada elemento. En vez de escribir `montos[0]`, `montos[1]`, `montos[2]`…, escribes el bloque una sola vez y Python lo repite por ti, sin importar cuántos elementos haya.

<Sintaxis lenguaje="python" codigo={"for elemento in coleccion:\n    # se ejecuta una vez por elemento"} />

**for básico.** En cada vuelta, la variable que escribes después de `for` toma el siguiente elemento. El nombre lo eliges tú: en singular, lo que es cada elemento (`nota` para una lista de `notas`).

```python
notas = [5.5, 3.8, 6.2]
for nota in notas:
    print(nota)
```

**Acumular.** Para sumar dentro de un `for`, crea la variable **antes** del ciclo (en 0) y actualízala en cada vuelta. Si la creas dentro, vuelve a 0 en cada vuelta y pierdes lo acumulado.

```python
unidades = [4, 10, 2]
total_unidades = 0
for cantidad in unidades:
    total_unidades = total_unidades + cantidad
```

**Contar lo que cumple una condición.** Un `if` dentro del `for` decide qué elementos cuentan. Fíjate en la sangría: el `if` está dentro del `for`, y lo que hace el `if` va un nivel más adentro.

```python
reprobados = 0
for nota in notas:
    if nota < 4:
        reprobados = reprobados + 1
```

**Recorrer una tabla.** Si la colección es una lista de diccionarios, cada vuelta te entrega una fila completa y lees sus columnas por clave: `for venta in ventas: print(venta["producto"])`.

<Debrief>
```python
total = 0
ventas_grandes = 0

for monto in montos:
    total = total + monto
    if monto > 100000:
        ventas_grandes = ventas_grandes + 1
```

Con la lista de la tarea, `total` es 675000 y `ventas_grandes` es 2. Un solo recorrido resolvió las dos preguntas: el patrón "crear antes, actualizar dentro" sirve para sumar, contar o buscar el máximo.
</Debrief>

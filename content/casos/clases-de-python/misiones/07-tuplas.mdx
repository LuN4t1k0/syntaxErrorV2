<Concepto>
Una tupla es una colección ordenada, como una lista, pero que no se puede modificar después de creada: no se agregan, quitan ni cambian elementos. Se usa para valores que van juntos y no deberían cambiar por separado, como las coordenadas de un punto o las medidas de una caja.

<Sintaxis lenguaje="python" codigo={"tupla = (valor1, valor2, valor3)"} />

**Crear una tupla.** Los valores van entre paréntesis, separados por comas.

```python
ubicacion = (-33.45, -70.66)   # latitud y longitud de Santiago
```

**Leer por posición.** Igual que en una lista: el índice empieza en 0.

```python
ubicacion[0]   # -33.45
```

**Desempaquetar.** Puedes repartir los valores de una tupla en varias variables en una sola línea. Debe haber tantas variables como elementos.

```python
latitud, longitud = ubicacion
```

**Por qué no se pueden cambiar.** `ubicacion[0] = 0` da un `TypeError`. Esa rigidez es una ventaja: si un valor no debe cambiar, la tupla te protege de modificarlo por error. Si necesitas cambiarla, creas una tupla nueva.
</Concepto>

<Debrief>
```python
caja = (40, 30, 20)

largo, ancho, alto = caja
volumen = largo * ancho * alto   # 24000
```

Desempaquetar le pone nombre a cada posición: `largo * ancho * alto` se entiende mucho mejor que `caja[0] * caja[1] * caja[2]`.
</Debrief>

<Concepto>
Un informe rara vez pide un solo número por grupo: quiere el total, el promedio y la cantidad de ventas de cada categoría, juntos en una tabla. `agg` calcula varios resúmenes en un solo paso.

<Sintaxis lenguaje="python" codigo={"df.groupby(\"grupo\")[\"columna\"].agg([\"sum\", \"mean\", \"count\"])"} />

**Varias funciones sobre una columna.** Con una lista de nombres de funciones, `agg` devuelve un DataFrame: una fila por grupo y una columna por función.

```python
notas = encuesta.groupby("canal")["calificacion"].agg(["mean", "min", "count"])
```

**Leer un valor.** Con `loc`, la etiqueta del grupo y el nombre de la columna.

```python
notas.loc["web", "min"]
```

**Columnas con nombre propio.** Cuando resumes columnas distintas, o quieres nombres claros para el informe, escribe cada columna nueva como `nombre=("columna", "función")`. Es la forma más legible y la que más se usa en el trabajo real.

```python
encuesta.groupby("canal").agg(
    respuestas=("respondent_id", "count"),
    nota_promedio=("calificacion", "mean"),
    edad_promedio=("edad", "mean"),
)
```

**Los grupos como columna.** Por defecto, los grupos quedan en el índice. Con `groupby(..., as_index=False)` quedan como una columna normal, lo que sirve cuando después vas a exportar la tabla o combinarla con otra.
</Concepto>

<Debrief>
```python
resumen_categoria = ventas.groupby("categoria")["monto"].agg(["sum", "mean", "count"])
promedio_hogar = resumen_categoria.loc["hogar", "mean"]   # 72750

informe_region = ventas.groupby("region").agg(
    total=("monto", "sum"),
    unidades=("cantidad", "sum"),
)
```

Hogar tiene 4 ventas con un promedio de 72750 y tecnología, 8 con un promedio de 168250. Con el promedio y la cantidad juntos se ve algo que el total solo no muestra: tecnología vende más porque vende más veces y además más caro.
</Debrief>

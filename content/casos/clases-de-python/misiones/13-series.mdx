<Concepto>
pandas es la librería de Python para trabajar con tablas de datos. Se importa una vez al principio, siempre con el mismo apodo: `pd`. Su pieza más simple es la Series: una columna de datos con un índice que numera cada valor.

<Sintaxis lenguaje="python" codigo={"import pandas as pd\nserie = pd.Series([valor1, valor2, valor3])"} />

**Crear una Series.** `pd.Series` recibe una lista. A la izquierda de cada valor, pandas muestra su índice (0, 1, 2…).

```python
import pandas as pd
precios = pd.Series([12000, 25000, 150000, 8000])
```

**Resumir sin un for.** Lo que en la lección de `for` hacías con un ciclo, una Series lo trae listo: `.sum()`, `.mean()` (promedio), `.max()`, `.min()` y `.count()` calculan sobre todos los valores de una vez.

```python
precios.mean()   # 48750.0
precios.min()    # 8000
```

**Operar con toda la columna.** Una operación aritmética con una Series se aplica a cada valor y devuelve otra Series del mismo largo. Es como un `for` que no tienes que escribir.

```python
precios * 1.19       # cada precio con IVA
precios >= 20000     # una Series de True y False
```

**Los números de pandas.** Si imprimes `precios.sum()`, quizás veas `np.int64(195000)`. Es un número de numpy, la librería sobre la que se construye pandas, y funciona igual que un `int`: puedes sumarlo, compararlo o guardarlo en una variable sin convertirlo.
</Concepto>

<Debrief>
```python
notas = pd.Series([5, 3, 4, 2, 4, 5])

promedio = notas.mean()   # 3.83…
mejor = notas.max()       # 5
notas_100 = notas * 20    # 100, 60, 80, 40, 80, 100
```

Ninguna línea necesitó un `for`: la Series aplica la operación a todos sus valores. Esa es la idea central de pandas, y la vas a usar en todas las lecciones que siguen.
</Debrief>

<Concepto>
Una fila duplicada es un registro que aparece dos veces: una exportación que se corrió dos veces o un sensor que envió la misma lectura repetida. Si no los quitas, cada duplicado se suma dos veces y los totales quedan inflados.

<Sintaxis lenguaje="python" codigo={"df.drop_duplicates()"} />

**Detectarlos.** `duplicated()` marca con `True` cada fila que es copia exacta de una anterior. La primera aparición queda en `False`, porque es la original. Sumado, cuenta cuántas copias sobran.

```python
pedidos.duplicated().sum()
```

**Mirarlos antes de borrar.** Con `keep=False` se marcan todas las apariciones, incluida la original, para ver juntos los registros repetidos y confirmar que de verdad son copias.

```python
pedidos[pedidos.duplicated(keep=False)]
```

**Eliminarlos.** `drop_duplicates()` devuelve la tabla con una sola aparición de cada fila repetida. Como casi todo en pandas, no cambia la tabla original: guarda el resultado.

```python
pedidos_limpios = pedidos.drop_duplicates()
```

**Duplicados por algunas columnas.** A veces dos filas no son idénticas, pero no deberían existir las dos: un mismo número de pedido no debería aparecer dos veces, aunque cambie otra columna. `subset` revisa solo las columnas que definen un registro único.

```python
pedidos.duplicated(subset=["pedido_id"])
```

<Debrief>
```python
copias_sobrantes = sensor.duplicated().sum()          # 2
repetidas = sensor[sensor.duplicated(keep=False)]     # 4 filas: dos pares

sensor_limpio = sensor.drop_duplicates()
filas_limpias = len(sensor_limpio)                    # 9
```

`drop_duplicates(keep=False)` también existe, pero borra todas las apariciones, incluidas las originales, y perderías lecturas válidas. Por defecto se conserva la primera.

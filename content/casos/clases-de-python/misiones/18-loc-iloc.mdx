<Concepto>
Para elegir filas, pandas tiene dos herramientas: `iloc` busca por **posición** (la primera fila, la tercera, las últimas cinco) y `loc` busca por **etiqueta**, es decir, por el valor del índice. Las dos aceptan también la columna, separada por una coma.

<Sintaxis lenguaje="python" codigo={"df.iloc[posicion_fila, posicion_columna]\ndf.loc[etiqueta_fila, \"columna\"]"} />

**iloc: por posición.** Funciona como los índices de una lista: empieza en 0, acepta negativos y rebanadas. `iloc[1:4]` toma las posiciones 1, 2 y 3: el final no se incluye.

```python
ventas.iloc[0]       # la primera fila
ventas.iloc[-1]      # la última fila
ventas.iloc[1:4]     # las filas en posición 1, 2 y 3
```

**Un índice con significado.** Por defecto, el índice de un DataFrame es 0, 1, 2… Con `set_index` puedes usar una columna como índice, por ejemplo el número de cada venta.

```python
por_venta = ventas.set_index("venta_id")
```

**loc: por etiqueta.** Ahora `loc[5]` busca la fila cuyo índice es 5, sin importar en qué posición esté. Con una coma eliges además la columna por su nombre.

```python
por_venta.loc[5]                # la venta número 5
por_venta.loc[5, "producto"]    # su producto
```

**Cuál usar.** `iloc` cuando te importa el lugar ("las tres primeras", "la última"); `loc` cuando te importa la identidad ("la persona 10", "la región norte"). Si el orden de la tabla cambia, `loc` sigue apuntando al mismo registro y `iloc` no.
</Concepto>

<Debrief>
```python
ultimas = encuesta.iloc[-3:]

por_id = encuesta.set_index("respondent_id")
edad_10 = por_id.loc[10, "edad"]    # 61
canal_7 = por_id.loc[7, "canal"]    # "app"
```

`encuesta.iloc[10]` es la fila en la posición 10, que corresponde a la persona con id 11, porque las posiciones empiezan en 0. Con el id como índice, `loc[10]` encuentra a la persona correcta aunque la tabla se ordene o se filtre.
</Debrief>

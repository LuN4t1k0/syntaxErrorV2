<Concepto>
Este proyecto junta todo el curso en un solo análisis. El archivo `datos/ventas_crudo.csv` es una exportación de ventas con los problemas de siempre: filas repetidas, una venta sin categoría, la misma categoría escrita de varias formas y ventas de dos meses distintos. La pregunta es simple: **¿cuánto vendió cada categoría en enero de 2026?**

<Sintaxis lenguaje="python" codigo={"cargar → mirar → limpiar → filtrar → agrupar → exportar → revisar"} />

**1. Cargar y mirar.** Antes de limpiar, ejecuta `head()`, `info()` y `unique()` sobre las columnas sospechosas. Limpiar sin mirar es adivinar.

**2. El orden de la limpieza importa.** Primero normaliza el texto y después quita duplicados. Dos filas pueden ser la misma venta aunque una diga `"hogar "` y la otra `"Hogar"`: solo son idénticas después de normalizar. Si quitas duplicados antes, esa copia sobrevive y el total de esa categoría queda inflado.

**3. Decidir sobre los vacíos.** Una venta sin categoría no se puede asignar a ningún grupo. Aquí la quitamos con `dropna`, pero en un informe real lo dirías: "se excluyó una venta de 25000 sin categoría".

**4. Filtrar el período.** Convierte la fecha con `pd.to_datetime` y quédate con el rango de enero: desde el 1 de enero y antes del 1 de febrero.

**5. Resumir, exportar y revisar.** Agrupa por categoría con `as_index=False`, exporta con `index=False` y vuelve a leer el archivo para confirmar cómo quedó.

**Un consejo de trabajo.** Escribe un paso, ejecuta, mira el resultado y recién después escribe el siguiente. `len(ventas)` después de cada paso te dice cuántas filas eliminó cada decisión.
</Concepto>

```python
ventas = pd.read_csv("datos/ventas_crudo.csv")

ventas["categoria"] = ventas["categoria"].str.strip().str.lower()
ventas = ventas.drop_duplicates()
ventas = ventas.dropna(subset=["categoria"])

ventas["fecha"] = pd.to_datetime(ventas["fecha"])
ventas = ventas[(ventas["fecha"] >= "2026-01-01") & (ventas["fecha"] < "2026-02-01")]

resumen = ventas.groupby("categoria", as_index=False)["monto"].sum()
resumen.to_csv("resumen_enero.csv", index=False)
final = pd.read_csv("resumen_enero.csv")
```

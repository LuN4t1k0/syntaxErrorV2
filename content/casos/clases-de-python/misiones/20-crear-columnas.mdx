<Concepto>
Muchas preguntas se responden con una columna que todavía no existe: el precio unitario, el monto con IVA, si una venta fue grande. En pandas, una columna nueva se crea asignándole una operación sobre otras columnas, y se calcula para todas las filas a la vez.

<Sintaxis lenguaje="python" codigo={"df[\"nueva\"] = expresión con otras columnas"} />

**Asignar una columna.** Se escribe como si leyeras una columna, pero a la izquierda del `=`. Si la columna no existe, se crea al final; si existe, se reemplaza.

```python
ventas["monto_con_iva"] = ventas["monto"] * 1.19
```

**Operar entre columnas.** Dos columnas se combinan fila por fila: el precio de la fila 0 con el stock de la fila 0, y así con cada fila.

```python
inventario["valor"] = inventario["precio"] * inventario["stock"]
```

**Una columna de True y False.** Una comparación también se puede guardar como columna. Sirve para marcar filas sin eliminarlas.

```python
ventas["es_norte"] = ventas["region"] == "norte"
```

**Contar con una columna booleana.** Al sumar `True` y `False`, pandas cuenta cada `True` como 1 y cada `False` como 0. Entonces `.sum()` de una columna booleana dice cuántas filas cumplen la condición, y `.mean()` qué proporción.

```python
ventas["es_norte"].sum()    # cuántas ventas son del norte
ventas["es_norte"].mean()   # qué fracción del total
```

<Concepto>
`if` permite que un programa tome decisiones: ejecuta un bloque de código solo si una condición es verdadera. Con `elif` y `else` se agregan otros caminos, y Python sigue exactamente uno de ellos.

<Sintaxis lenguaje="python" codigo={"if condicion:\n    # si la condición es verdadera\nelif otra_condicion:\n    # si la primera no se cumplió y esta sí\nelse:\n    # si ninguna se cumplió"} />

**if simple.** La línea del `if` termina en dos puntos, y el bloque de abajo va con sangría (cuatro espacios). Si la condición es falsa, Python se salta el bloque completo.

```python
if nota < 4:
    print("Reprobado")
```

**if / else.** `else` cubre todo lo que no cumplió la condición. Siempre se ejecuta uno de los dos bloques: nunca ninguno, nunca los dos.

```python
if nota >= 4:
    resultado = "Aprobado"
else:
    resultado = "Reprobado"
```

**elif para más de dos caminos.** Python revisa las condiciones de arriba hacia abajo y entra en la **primera** que se cumple; las demás ya no se revisan. Por eso el orden importa: la condición más específica va primero.

```python
if nota >= 6:
    resultado = "Destacado"
elif nota >= 4:
    resultado = "Aprobado"
else:
    resultado = "Reprobado"
```

Con `nota = 6.5`, las dos primeras condiciones son verdaderas, pero Python entra solo en la primera. Si invirtieras el orden, un 6.5 quedaría como "Aprobado".
</Concepto>

<Debrief>
```python
if stock == 0:
    estado = "Agotado"
elif stock < 5:
    estado = "Reponer"
else:
    estado = "OK"
```

La prueba corrió tu código con stock 3, 0, 12, 5 y 4. Un código que funciona solo con el valor que ves ahora no es una decisión: es un resultado escrito a mano. Fíjate también en los bordes: con `stock = 5`, `< 5` es falso y el producto queda "OK".

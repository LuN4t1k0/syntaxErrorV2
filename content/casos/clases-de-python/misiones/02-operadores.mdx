<Concepto>
Los operadores combinan valores para producir uno nuevo. Hay tres familias: los aritméticos calculan números, los de comparación responden una pregunta con `True` o `False`, y los lógicos combinan varias de esas respuestas.

<Sintaxis lenguaje="python" codigo={"resultado = valor1 operador valor2"} />

**Aritméticos.** `+` suma, `-` resta, `*` multiplica, `/` divide (siempre da un `float`), `//` divide y descarta los decimales, `%` da el resto de la división y `**` eleva a una potencia. Igual que en matemáticas, la multiplicación va antes que la suma: usa paréntesis cuando quieras otro orden.

```python
precio = 25000
descuento = 0.2
precio_final = precio * (1 - descuento)   # 20000.0
cajas = 17 // 5                           # 3 cajas completas
sueltas = 17 % 5                          # sobran 2
```

**De comparación.** `==` pregunta si dos valores son iguales (uno solo, `=`, es para asignar), `!=` si son distintos, y `<`, `>`, `<=`, `>=` comparan magnitudes. El resultado es siempre un `bool`, y se puede guardar en una variable.

```python
stock = 8
hay_poco = stock < 10       # True
agotado = stock == 0        # False
```

**Lógicos.** `and` es `True` solo si las dos condiciones lo son, `or` basta con que una lo sea, y `not` invierte una condición.

```python
oferta = precio < 30000 or descuento >= 0.5   # barato o con gran descuento
```

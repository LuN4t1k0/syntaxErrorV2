<Concepto>
Una función le pone nombre a un cálculo para reutilizarlo. En vez de copiar la misma fórmula cada vez que la necesitas, la escribes una vez y después la llamas con distintos valores. Si mañana cambia la fórmula, la corriges en un solo lugar.

<Sintaxis lenguaje="python" codigo={"def nombre_funcion(parametro1, parametro2):\n    return valor"} />

**Definir.** `def`, el nombre, los parámetros entre paréntesis y dos puntos. El cuerpo va con sangría. Los parámetros son los nombres que tendrán, dentro de la función, los valores que le pasen.

```python
def calcular_total(precio, cantidad):
    return precio * cantidad
```

**return devuelve el resultado.** `return` entrega un valor a quien llamó la función, y la función termina ahí. Sin `return`, la función devuelve `None`. Ojo: `print` dentro de la función muestra el valor, pero no lo devuelve; para usar el resultado después, necesitas `return`.

**Llamar.** Se escribe el nombre con los valores entre paréntesis, en el mismo orden que los parámetros. Lo que devuelve se puede guardar en una variable o usar en otro cálculo.

```python
total = calcular_total(450000, 3)          # 1350000
doble = calcular_total(12000, 2) * 2       # 48000
```

**Valores por defecto.** Un parámetro puede tener un valor que se usa si no lo pasan. Así la función sirve para el caso común y para el especial.

```python
def precio_con_iva(neto, iva=0.19):
    return neto * (1 + iva)

precio_con_iva(10000)         # 11900.0
precio_con_iva(10000, 0)      # 10000: un producto exento
```

<Debrief>
```python
def calcular_total(precio, cantidad, descuento=0):
    return precio * cantidad * (1 - descuento)

total_notebooks = calcular_total(450000, 3, 0.1)   # 1215000.0
total_mouse = calcular_total(12000, 2)             # 24000
```

La prueba llamó tu función con otros valores para comprobar que usa sus parámetros. Y como `descuento` tiene valor por defecto, la misma función sirve para ventas con y sin descuento.

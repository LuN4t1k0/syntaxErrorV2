<Concepto>
Una lista puede guardar cualquier valor, incluidos diccionarios. Una lista de diccionarios con las mismas claves es la forma natural de representar una tabla en Python, antes de conocer pandas: cada diccionario es una fila y cada clave es una columna.

<Sintaxis lenguaje="python" codigo={"tabla = [{\"columna\": valor}, {\"columna\": valor}]"} />

**Una tabla de clientes.** Cada cliente es un diccionario. Para que se lea mejor, se suele escribir una fila por línea.

```python
clientes = [
    {"nombre": "Ana", "ciudad": "Temuco"},
    {"nombre": "Luis", "ciudad": "Arica"},
    {"nombre": "Rosa", "ciudad": "Talca"},
]
```

**Primero la fila, después la columna.** `clientes[0]` es el diccionario completo del primer cliente; `clientes[0]["nombre"]` es el valor de una de sus claves. Se lee de izquierda a derecha.

```python
clientes[0]              # {"nombre": "Ana", "ciudad": "Temuco"}
clientes[0]["nombre"]    # "Ana"
clientes[-1]["ciudad"]   # "Talca"
```

**Agregar una fila.** Como `clientes` es una lista, `append` agrega un diccionario nuevo al final, con las mismas claves que las demás filas.

```python
clientes.append({"nombre": "Pedro", "ciudad": "Osorno"})
```

**Lo que viene.** En la lección de `for` vas a recorrer las filas una por una, y con pandas vas a trabajar estas mismas tablas mucho más rápido.

<Concepto>
Una tabla con doce números se lee; una con mil, no. Un gráfico bien elegido muestra en un segundo el patrón que la tabla esconde. La elección no depende de qué gráfico se ve más lindo, sino de **qué pregunta** quieres responder.

**Barras: comparar categorías.** ¿Qué región vendió más? ¿Qué canal trae más respuestas? Cada barra es una categoría y su largo es el valor. Ordena las barras de mayor a menor y empieza el eje en 0: si el eje parte en 600000, una diferencia de 8 % parece el doble.

**Líneas: cambio en el tiempo.** ¿Cómo evolucionaron las ventas mes a mes? El eje horizontal es el tiempo y la línea une puntos consecutivos, así que se lee como una tendencia. Si el eje horizontal no es tiempo (por ejemplo, regiones), una línea sugiere una continuidad que no existe.

**Histograma: cómo se reparten los valores.** ¿Las ventas son casi todas chicas, con unas pocas muy grandes? Agrupa los valores en tramos y muestra cuántos caen en cada uno. Sirve para ver la forma de los datos y detectar valores raros.

**Dispersión: relación entre dos números.** ¿Las personas mayores ponen mejores notas? Cada punto es una fila, con un valor en cada eje. Muestra si dos variables se mueven juntas, aunque eso no prueba que una cause la otra.

**Torta: con cuidado.** Solo funciona para mostrar partes de un todo con pocas categorías (dos o tres). Con más, comparar ángulos es difícil y un gráfico de barras lo comunica mejor.

**Con pandas y matplotlib.** En tu computadora o en Google Colab, pandas grafica directo desde un resultado. Este editor todavía no muestra gráficos, pero el código es así:

```python
import matplotlib.pyplot as plt

por_region = ventas.groupby("region")["monto"].sum().sort_values(ascending=False)
por_region.plot(kind="bar", title="Ventas por región")
plt.show()
```

`kind` puede ser `"bar"`, `"line"`, `"hist"`, `"scatter"` o `"pie"`. En el curso de Power BI vas a construir estos mismos gráficos de forma interactiva.

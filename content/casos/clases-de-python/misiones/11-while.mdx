<Concepto>
`while` repite un bloque mientras una condición siga siendo verdadera. A diferencia de `for`, no recorre una colección: no sabe de antemano cuántas vueltas va a dar. Sirve cuando la cantidad de repeticiones depende de algo que va cambiando.

<Sintaxis lenguaje="python" codigo={"while condicion:\n    # se repite mientras sea verdadera"} />

**Cómo avanza.** Antes de cada vuelta, Python revisa la condición. Si es verdadera, ejecuta el bloque y vuelve a revisar; si es falsa, sigue con lo que viene después del `while`. Si la condición es falsa desde el principio, el bloque no se ejecuta ni una vez.

```python
contador = 0
while contador < 3:
    contador = contador + 1
# aquí contador vale 3
```

**Cuidado con los ciclos infinitos.** Algo dentro del bloque tiene que acercar la condición a ser falsa. Si olvidas actualizar la variable, el `while` se repite para siempre. En esta plataforma, tu código se detiene a los 10 segundos y te avisa.

```python
# ciclo infinito: saldo nunca cambia
while saldo > 0:
    pagos = pagos + 1
```

**Contar vueltas.** Igual que en un `for`, una variable creada antes del ciclo puede contar cuántas veces se repitió.

```python
saldo = 100000
meses = 0
while saldo > 0:
    saldo = saldo - 30000
    meses = meses + 1
# meses = 4: el último pago deja el saldo en -20000
```

<Debrief>
```python
pedidos = 0

while stock >= 3:
    stock = stock - 3
    pedidos = pedidos + 1
```

Con 20 unidades salen 6 pedidos y sobran 2. La condición `>= 3` es la clave: con `> 3`, un stock de exactamente 3 no despacharía nada, y con `>= 0` se despacharía un pedido de más y el stock quedaría negativo.
</Debrief>

<Concepto>
"¿Cuánto vendió cada región?" es una pregunta por grupo: separar las filas según una columna, calcular algo en cada grupo y juntar los resultados. Es lo que en Excel haces con una tabla dinámica y en SQL con `GROUP BY`. En pandas, `groupby`.

<Sintaxis lenguaje="python" codigo={"df.groupby(\"columna_grupo\")[\"columna_valor\"].sum()"} />

**Se lee en tres partes.** Agrupa por categoría, toma la columna cantidad y suma en cada grupo.

```python
ventas.groupby("categoria")["cantidad"].sum()
```

El resultado es una Series: el índice son las categorías (ordenadas alfabéticamente) y los valores son los totales.

**Otras funciones.** En lugar de `sum` puedes usar `mean`, `count`, `max` o `min`. `count` cuenta filas con dato en esa columna: cuántas respuestas tuvo cada canal.

```python
encuesta.groupby("canal")["calificacion"].mean()
encuesta.groupby("canal")["respondent_id"].count()
```

**Leer un grupo.** Como los canales quedaron en el índice, un grupo se lee por su etiqueta.

```python
nota_por_canal = encuesta.groupby("canal")["calificacion"].mean()
nota_por_canal["app"]
```

**El grupo ganador.** `idxmax()` devuelve la etiqueta del valor más alto (y `idxmin()`, la del más bajo). `max()` daría la nota; `idxmax()` dice de qué canal es.

```python
nota_por_canal.idxmin()   # el canal con la nota promedio más baja
```

```python
por_region = ventas.groupby("region")["monto"].sum()
# centro 648000, norte 697000, sur 292000

total_norte = por_region["norte"]   # 697000
region_top = por_region.idxmax()    # "norte"
```

`region_top` sale del cálculo y no de mirar la tabla: si mañana llegan las ventas de abril, el mismo código responde de nuevo sin cambiar nada.

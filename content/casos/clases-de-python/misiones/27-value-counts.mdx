<Concepto>
"¿Por qué canal llegan más respuestas?" se responde contando cuántas veces aparece cada valor de una columna. `value_counts` lo hace en una línea y ordena el resultado de mayor a menor.

<Sintaxis lenguaje="python" codigo={"df[\"columna\"].value_counts()"} />

**Contar.** El resultado es una Series: el índice son los valores distintos y los números, cuántas veces aparece cada uno. El más frecuente queda primero.

```python
ventas["producto"].value_counts()
```

**El más frecuente.** Como viene ordenado, el primer elemento del índice es el valor más común.

```python
ventas["producto"].value_counts().index[0]   # "Mouse"
```

**Proporciones.** Con `normalize=True`, en vez de cantidades da la fracción de cada valor sobre el total: 0.25 es un cuarto de las filas. Multiplicada por 100, es un porcentaje.

```python
ventas["categoria"].value_counts(normalize=True)
```

**value_counts o groupby.** `value_counts` responde una sola pregunta: cuántas filas hay de cada valor. Si necesitas sumar o promediar otra columna por grupo, usa `groupby`.
</Concepto>

<Debrief>
```python
por_canal = encuesta["canal"].value_counts()    # web 5, tienda 3, telefono 2, app 2
canal_top = por_canal.index[0]                   # "web"
porcentaje_web = encuesta["canal"].value_counts(normalize=True)["web"] * 100   # 41.7
```

`por_canal.index[0]` es la etiqueta ("web") y `por_canal.iloc[0]` es la cantidad (5). Confundirlos es uno de los errores más comunes al leer resultados de pandas.
</Debrief>

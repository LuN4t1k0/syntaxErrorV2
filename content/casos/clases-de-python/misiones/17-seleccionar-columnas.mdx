<Concepto>
Casi nunca necesitas todas las columnas de una tabla. Elegir las que importan hace que el análisis se lea mejor y que las tablas que muestras se entiendan de un vistazo.

<Sintaxis lenguaje="python" codigo={"df[\"columna\"]\ndf[[\"columna1\", \"columna2\"]]"} />

**Una columna: una Series.** Con el nombre entre corchetes obtienes la columna como Series.

```python
ventas["producto"]
```

**Varias columnas: un DataFrame.** Con una **lista** de nombres obtienes un DataFrame más angosto, con las columnas en el orden en que las pediste. Por eso aparecen dos pares de corchetes: los de afuera seleccionan y los de adentro forman la lista.

```python
ventas[["producto", "monto"]]
```

**Los valores distintos.** `.unique()` devuelve los valores sin repetir de una columna, en el orden en que aparecen, y `.nunique()` cuenta cuántos son.

```python
ventas["region"].unique()    # norte, sur, centro
ventas["region"].nunique()   # 3
```

**Pasar a una lista de Python.** `.tolist()` convierte una Series (o lo que devuelve `unique`) en una lista común, sin el índice de pandas.

```python
ventas["region"].unique().tolist()   # ["norte", "sur", "centro"]
```

<Debrief>
```python
canales = encuesta["canal"]                                # una Series
perfil = encuesta[["edad", "canal"]]                       # un DataFrame
canales_distintos = encuesta["canal"].unique().tolist()    # ["web", "tienda", "telefono", "app"]
```

La diferencia entre `encuesta["canal"]` y `encuesta[["canal"]]` es el tipo de resultado: lo primero es una Series y lo segundo un DataFrame de una columna. `encuesta["edad", "canal"]`, sin la lista, busca una sola columna con ese nombre doble y da `KeyError`.
</Debrief>

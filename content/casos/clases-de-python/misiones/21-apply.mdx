<Concepto>
Las operaciones de la lección anterior cubren cálculos y comparaciones simples. Cuando la regla tiene varios casos, como clasificar edades en tramos, escribes una función con `if` y le pides a pandas que la aplique a cada valor de la columna con `apply`.

<Sintaxis lenguaje="python" codigo={"df[\"nueva\"] = df[\"columna\"].apply(nombre_funcion)"} />

**1. La función recibe un valor.** Piensa en una sola celda: la función recibe un valor y devuelve el resultado para ese valor. Puedes probarla sola antes de usarla con la tabla.

```python
def tramo_monto(monto):
    if monto >= 100000:
        return "alto"
    return "bajo"

tramo_monto(150000)   # "alto"
```

**2. apply la usa en cada fila.** `apply` llama a la función una vez por cada valor y devuelve una Series con los resultados. La función se pasa **sin paréntesis**: le entregas la función para que pandas la llame, no su resultado.

```python
ventas["tramo"] = ventas["monto"].apply(tramo_monto)
```

Si escribes `apply(tramo_monto())`, Python intenta llamar la función en ese momento, sin el monto, y da un `TypeError`.

**Cuándo no hace falta.** Si la regla es una sola comparación o una operación aritmética, la forma directa de la lección anterior es más corta y más rápida. `apply` brilla cuando la regla tiene varios caminos.
</Concepto>

<Debrief>
```python
def grupo_edad(edad):
    if edad < 30:
        return "joven"
    elif edad < 50:
        return "adulto"
    else:
        return "mayor"

encuesta["grupo"] = encuesta["edad"].apply(grupo_edad)
jovenes = (encuesta["grupo"] == "joven").sum()   # 5
```

La prueba llamó a `grupo_edad` con 29, 30, 49 y 50: los bordes son donde más se equivoca una regla. Con `elif edad <= 50`, una persona de 50 quedaría como "adulto".
</Debrief>

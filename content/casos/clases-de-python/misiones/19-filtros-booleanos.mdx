<Concepto>
Filtrar es quedarse solo con las filas que cumplen una condición: las ventas de marzo, las respuestas con nota baja, los clientes de una región. En pandas se hace en dos pasos, aunque casi siempre se escriben en una línea.

<Sintaxis lenguaje="python" codigo={"df[df[\"columna\"] > valor]"} />

**1. La máscara.** Una comparación sobre una columna no da un solo `True` o `False`: da una Series con un `True` o `False` por fila. A eso se le llama máscara booleana.

```python
ventas["monto"] > 100000   # True, False, False, …
```

**2. Filtrar con la máscara.** Si pones la máscara entre corchetes, el DataFrame devuelve solo las filas donde la máscara es `True`. El resultado es otro DataFrame: la tabla original no cambia.

```python
ventas_grandes = ventas[ventas["monto"] > 100000]
```

**Combinar condiciones: & y |.** Para dos condiciones a la vez se usa `&` (y) y para una u otra, `|` (o). Cada condición va **entre paréntesis**. Con `and` u `or`, pandas da un error, porque esas palabras esperan un solo `True` o `False`, no una columna entera.

```python
ventas[(ventas["region"] == "sur") & (ventas["monto"] > 40000)]
ventas[(ventas["region"] == "norte") | (ventas["region"] == "centro")]
```

**isin: varios valores permitidos.** Cuando la condición es "que sea uno de estos", `isin` es más corto que encadenar `|`.

```python
ventas[ventas["region"].isin(["norte", "centro"])]
```

**Contar lo filtrado.** `len(filtrado)` dice cuántas filas cumplieron la condición.

<Debrief>
```python
satisfechos = encuesta[encuesta["calificacion"] >= 4]   # 7 respuestas

web_satisfechos = encuesta[(encuesta["calificacion"] >= 4) & (encuesta["canal"] == "web")]
cantidad_web_satisfechos = len(web_satisfechos)          # 4

presenciales = encuesta[encuesta["canal"].isin(["tienda", "telefono"])]
```

Si escribes `and` en vez de `&`, pandas reclama que el valor de verdad de una Series es ambiguo: no sabe si quieres que todas las filas, o alguna, sean `True`. `&` compara fila por fila, que es lo que necesitas para filtrar.
</Debrief>

<Concepto>
Una lista guarda varios valores en orden, dentro de una sola variable. En vez de `precio1`, `precio2` y `precio3`, tienes `precios` con los tres adentro. Es la estructura que más vas a usar en Python.

<Sintaxis lenguaje="python" codigo={"lista = [valor1, valor2, valor3]"} />

**Crear una lista.** Los valores van entre corchetes, separados por comas. Puede tener cualquier cantidad de elementos, incluso ninguno: `[]`.

```python
precios = [450000, 12000, 25000]
```

**Leer por posición.** Cada elemento tiene un índice que empieza en 0: `precios[0]` es el primero y `precios[1]` el segundo. Los índices negativos cuentan desde el final: `precios[-1]` es el último, sin importar cuántos haya.

```python
precios[0]    # 450000
precios[-1]   # 25000
```

**Cambiar la lista.** A diferencia de un número o un texto, una lista se modifica después de creada. `append` agrega un elemento al final, y asignar a una posición reemplaza ese elemento.

```python
precios.append(180000)   # [450000, 12000, 25000, 180000]
precios[1] = 13000       # [450000, 13000, 25000, 180000]
```

**Contar y resumir.** `len(lista)` dice cuántos elementos tiene; `sum`, `max` y `min` calculan sobre todos los números de la lista.

```python
len(precios)   # 4
sum(precios)   # 668000
```

<Debrief>
```python

primero = precios[0]       # 450000
ultimo = precios[-1]       # 95000
cantidad = len(precios)    # 5
```

El orden importa: si lees `precios[-1]` antes del `append`, obtienes 180000, porque en ese momento todavía era el último. Python ejecuta las líneas de arriba hacia abajo.

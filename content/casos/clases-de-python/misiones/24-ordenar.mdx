<Concepto>
Ordenar responde preguntas de ranking: las ventas más grandes, los productos más baratos, las respuestas más recientes. `sort_values` ordena las filas según una o más columnas.

<Sintaxis lenguaje="python" codigo={"df.sort_values(\"columna\", ascending=False)"} />

**De menor a mayor.** Es el orden por defecto. Los textos se ordenan alfabéticamente y las fechas, de la más antigua a la más reciente.

```python
encuesta.sort_values("edad")
```

**De mayor a menor.** `ascending=False` invierte el orden.

```python
encuesta.sort_values("edad", ascending=False)
```

**El original no cambia.** `sort_values` devuelve una tabla nueva y deja `encuesta` como estaba. Si quieres conservar el orden, guarda el resultado en una variable.

**Los primeros del ranking.** Ordena y después toma las primeras filas con `head`. Con `iloc[0]` obtienes solo la primera.

```python
mayores = encuesta.sort_values("edad", ascending=False)
mayores.head(2)
mayores.iloc[0]["canal"]
```

**Varias columnas.** Con una lista de columnas, pandas ordena por la primera y usa la segunda para desempatar. `ascending` puede llevar una lista con el sentido de cada columna.

```python
encuesta.sort_values(["canal", "calificacion"], ascending=[True, False])
```

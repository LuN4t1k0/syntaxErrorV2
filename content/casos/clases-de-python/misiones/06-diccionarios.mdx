<Concepto>
Un diccionario guarda pares clave-valor. En una lista buscas por posición (`precios[0]`); en un diccionario buscas por nombre (`producto["precio"]`). Es la forma natural de representar un registro con varios campos, como una fila de una planilla.

<Sintaxis lenguaje="python" codigo={"diccionario = {\"clave\": valor}"} />

**Crear un diccionario.** Va entre llaves. Cada par se escribe como clave, dos puntos y valor, y los pares se separan con comas. Las claves suelen ser textos.

```python
cliente = {"nombre": "Ana", "ciudad": "Temuco", "compras": 4, "total_gastado": 180000}
```

**Leer un valor.** El nombre de la clave va entre corchetes. Si la clave no existe, Python da un `KeyError`: revisa que esté escrita igual, con las mismas mayúsculas y tildes.

```python
cliente["ciudad"]   # "Temuco"
```

**Agregar o modificar.** La misma escritura sirve para las dos cosas: si la clave no existe, se agrega; si ya existe, se reemplaza su valor.

```python
cliente["email"] = "ana@correo.cl"   # agrega una clave nueva
cliente["compras"] = 5               # cambia el valor de una que ya existía
```

**Usar los valores en cálculos.** Lo que lees de un diccionario es un valor como cualquier otro: puedes guardarlo en una variable o usarlo en una operación.

```python
promedio = cliente["total_gastado"] / cliente["compras"]
```

<Debrief>
```python
producto["categoria"] = "tecnologia"   # clave nueva: se agrega
producto["stock"] = 5                  # clave existente: se reemplaza

valor_inventario = producto["precio"] * producto["stock"]   # 2250000
```

Al final, `producto` tiene cuatro claves. La misma escritura `producto["clave"] = valor` agrega o modifica según si la clave ya existía.

<Concepto>
Al leer un CSV, las fechas llegan como texto: `"2026-03-09"` son solo caracteres. Para preguntar por el mes, ordenar en el tiempo o filtrar un período, primero hay que convertirlas en fechas de verdad.

<Sintaxis lenguaje="python" codigo={"df[\"fecha\"] = pd.to_datetime(df[\"fecha\"])"} />

**Convertir.** `pd.to_datetime` recibe la columna de texto y devuelve una columna de fechas. Después de convertir, `info()` muestra el tipo `datetime64` en vez de `object`.

```python
pedidos["fecha_pedido"] = pd.to_datetime(pedidos["fecha_pedido"])
```

Si las fechas vienen como día/mes/año, por ejemplo `"09/03/2026"`, agrega `dayfirst=True`. Sin eso, pandas puede leer el 9 de marzo como 3 de septiembre.

**Extraer partes con .dt.** Igual que `.str` para textos, `.dt` da acceso a las partes de una fecha: `.dt.year`, `.dt.month`, `.dt.day` y `.dt.day_name()` para el día de la semana.

```python
pedidos["anio"] = pedidos["fecha_pedido"].dt.year
pedidos["dia"] = pedidos["fecha_pedido"].dt.day_name()   # "Monday", "Tuesday", …
```

**Filtrar un período.** Con la columna convertida, se compara contra una fecha escrita como texto, igual que con números. Para un mes completo, la forma más segura es "desde el primer día, y antes del primer día del mes siguiente": así no importa cuántos días tenga el mes.

```python
pedidos[(pedidos["fecha_pedido"] >= "2025-12-01") & (pedidos["fecha_pedido"] < "2026-01-01")]   # diciembre de 2025
```

<Debrief>
```python
ventas["fecha"] = pd.to_datetime(ventas["fecha"])
ventas["mes"] = ventas["fecha"].dt.month

ventas_marzo = ventas[(ventas["fecha"] >= "2026-03-01") & (ventas["fecha"] < "2026-04-01")]
total_marzo = ventas_marzo["monto"].sum()   # 830000
```

Con la columna `mes` también podías filtrar con `ventas[ventas["mes"] == 3]`. Funciona aquí porque todas las ventas son de 2026; con datos de varios años, marzo de 2025 y marzo de 2026 quedarían juntos. El rango de fechas no tiene ese problema.
</Debrief>

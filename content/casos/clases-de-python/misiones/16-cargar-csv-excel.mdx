<Concepto>
En el trabajo real los datos llegan en archivos: un CSV exportado de un sistema o una planilla de Excel. pandas los lee y los convierte en un DataFrame con una sola línea.

<Sintaxis lenguaje="python" codigo={"df = pd.read_csv(\"carpeta/archivo.csv\")"} />

**Un CSV es texto.** Cada línea es una fila y un separador divide las columnas. La primera línea suele traer los nombres de las columnas. Así se ve por dentro `datos/ventas.csv`:

```text
venta_id,fecha,region,categoria,producto,cantidad,monto
1,2026-01-08,norte,tecnologia,Notebook,1,450000
2,2026-01-15,sur,hogar,Lámpara,2,24000
```

**read_csv.** Recibe la ruta del archivo, relativa a donde corre tu código. En esta plataforma, los archivos del curso están en la carpeta `datos/`.

```python
encuesta = pd.read_csv("datos/encuesta.csv")
```

**Cuando el separador es punto y coma.** En Chile y otros países que usan la coma para los decimales, muchos sistemas exportan CSV separados por `;`. Si lo lees sin avisar, pandas encuentra una sola columna con todo el texto adentro. El parámetro `sep` le dice cuál es el separador.

```python
pd.read_csv("archivo.csv", sep=";")
```

**Revisar al cargar.** Después de cargar, mira el resultado antes de seguir: `head()` para ver las filas y `columns` para confirmar que las columnas se separaron bien.

**read_excel.** `pd.read_excel("archivo.xlsx", sheet_name="Hoja1")` funciona igual para planillas de Excel. En tu computadora necesita la librería `openpyxl` instalada. En el navegador de este curso trabajamos con CSV, que es el formato más común para intercambiar datos.
</Concepto>

<Concepto>
Una variable es un nombre que guarda un valor para usarlo después. En Python no se declara el tipo de antemano: la variable nace cuando le asignas un valor, y Python deduce el tipo por cómo lo escribiste.

<Sintaxis lenguaje="python" codigo={"nombre_variable = valor"} />

**Asignar una variable.** El signo `=` guarda el valor de la derecha en el nombre de la izquierda. No es una igualdad matemática: se lee "guarda 450000 en precio".

```python
precio = 450000
```

**Los cuatro tipos básicos.** `int` para enteros, `float` para números con decimales (con punto, no coma), `str` para texto entre comillas y `bool` para `True` o `False`, con mayúscula inicial y sin comillas.

```python
precio = 450000        # int
descuento = 0.1        # float
producto = "Notebook"  # str
disponible = True      # bool
```

Las comillas cambian el tipo: `450000` es un número con el que se puede calcular, y `"450000"` es un texto que solo se ve igual. Lo mismo pasa con `True` y `"True"`.

**Nombres que se entienden.** Un buen nombre dice qué guarda: `precio_unitario` se entiende solo, `x` no. Se escriben en minúsculas, con `_` entre palabras, sin tildes ni espacios.

**Cambiar el valor.** Una variable se puede volver a asignar en cualquier momento; el valor anterior se pierde. Y el lado derecho puede usar otras variables:

```python
stock = 3
stock = stock + 2   # ahora stock vale 5
```

**Comentarios con #.** Todo lo que viene después de `#` en una línea es un comentario: Python lo ignora. Sirve para explicarle el código a quien lo lea después, incluso a ti dentro de un mes.
</Concepto>

<Debrief>
```python
producto = "Notebook"
precio = 450000
stock = 3
disponible = True

valor_inventario = precio * stock   # 1350000
```

Escribir `precio * stock` en vez de `1350000` hace que el cálculo siga siendo correcto si mañana cambia el precio o el stock: solo cambias el valor de la variable y todo lo que depende de ella se actualiza.
</Debrief>

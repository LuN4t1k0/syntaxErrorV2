<Concepto>
Un DataFrame es una tabla completa: filas y columnas, como una hoja de Excel. Cada columna es una Series, así que todo lo que aprendiste en la lección anterior se aplica a cada columna. Es la estructura con la que vas a trabajar casi siempre.

<Sintaxis lenguaje="python" codigo={"df = pd.DataFrame({\"columna1\": [valores], \"columna2\": [valores]})"} />

**Crear un DataFrame desde un diccionario.** Cada clave es el nombre de una columna y su lista son los valores de esa columna, de arriba hacia abajo. Todas las listas deben tener el mismo largo: cada posición es una fila.

```python
clientes = pd.DataFrame({
    "nombre": ["Ana", "Luis", "Rosa"],
    "compras": [4, 1, 7],
})
```

En el panel de abajo del editor, al ejecutar, verás la tabla con sus filas numeradas desde 0.

**Leer una columna.** `df["columna"]` devuelve esa columna como una Series, con todos sus métodos.

```python
clientes["compras"]          # la columna completa
clientes["compras"].mean()   # 4.0
```

**Las columnas y el largo.** `df.columns` lista los nombres de las columnas y `len(df)` dice cuántas filas tiene.

```python
list(clientes.columns)   # ["nombre", "compras"]
len(clientes)            # 3
```

En la práctica casi nunca vas a escribir una tabla a mano: la vas a cargar desde un archivo. Pero armar una pequeña ayuda a entender qué es un DataFrame por dentro.

<Debrief>
```python
inventario = pd.DataFrame({
    "producto": ["Notebook", "Mouse", "Monitor"],
    "precio": [450000, 12000, 150000],
    "stock": [3, 25, 6],
})

precios = inventario["precio"]           # una Series
stock_total = inventario["stock"].sum()  # 34
```

Cada clave del diccionario se convirtió en una columna, y cada posición de las listas en una fila. Al leer una columna obtienes una Series, por eso `.sum()` funciona igual que en la lección anterior.
</Debrief>

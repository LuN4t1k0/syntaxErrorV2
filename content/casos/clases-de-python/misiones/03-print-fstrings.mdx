<Concepto>
`print` muestra un valor en la salida. Es la forma más simple de ver qué está pasando dentro de un programa: qué vale una variable, por qué camino pasó, cuál fue el resultado.

`print` solo muestra: no guarda nada. Si escribes `total = print(precio)`, el precio aparece en pantalla, pero `total` queda en `None` (vacío). Para guardar un valor se asigna directo, sin `print`.

<Sintaxis lenguaje="python" codigo={"print(f\"texto {variable} más texto\")"} />

**print básico.** Recibe un texto, un número o el resultado de una expresión. Cada `print` escribe una línea nueva.

```python
print("hola")
print(450000 * 3)
```

**f-strings.** Una `f` antes de las comillas convierte el texto en una plantilla: lo que pongas entre llaves `{}` se reemplaza por su valor. Todo lo demás (espacios, dos puntos, el signo `$`) se escribe tal cual.

```python
producto = "Teclado"
precio = 25000
print(f"Producto: {producto}, precio ${precio}")   # Producto: Teclado, precio $25000
```

Sin la `f`, Python imprime las llaves literalmente: `print("{producto}")` muestra `{producto}`.

**Expresiones dentro de las llaves.** Entre las llaves cabe cualquier expresión, no solo un nombre: un cálculo, una comparación o una llamada a una función.

```python
print(f"Tres unidades: ${precio * 3}")   # Tres unidades: $75000
```

<Debrief>
```python
print(f"{producto}: ${precio}")
print(f"Por 2 unidades: ${precio * 2}")
```

La salida muestra `Mouse: $12000` y `Por 2 unidades: $24000`. `print` sirve para mirar; cuando necesites usar el valor después, guárdalo en una variable: `linea = f"{producto}: ${precio}"`.

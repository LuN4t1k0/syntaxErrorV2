<Concepto>
Power Query es la parte de Power BI que limpia y transforma los datos **antes** de que lleguen al modelo: cambiar tipos de dato, quitar columnas, filtrar filas, corregir textos, combinar tablas. Es el mismo motor que existe en Excel (pestaña Datos > Obtener y transformar).

**Pasos que se repiten solos.** Cada cosa que haces con un clic queda registrada como un paso en la lista "Pasos aplicados". Cuando llegue el archivo del mes siguiente, Power BI repite todos los pasos automáticamente al actualizar: limpias una vez y queda limpio para siempre. Es la diferencia con corregir a mano en Excel cada mes.

**El lenguaje M.** Detrás de cada clic, Power Query escribe código en un lenguaje llamado M. No necesitas escribirlo en este curso, pero conviene reconocerlo cuando lo veas en la barra de fórmulas:

```text
= Table.SelectRows(ventas, each [region] = "norte")
```

**Por qué limpiar antes de cargar.** Si una región viene escrita como "Norte" y como "norte", y no lo corriges en Power Query, cada gráfico, medida y filtro va a mostrar dos regiones distintas. Corregirlo en el origen lo arregla una vez para todo el reporte. Corregirlo después con fórmulas obliga a repetir el arreglo en cada lugar donde se use esa columna.

**Dónde se abre.** Pestaña Inicio > "Transformar datos". O, al cargar un archivo, el botón "Transformar datos" en vez de "Cargar".
</Concepto>

<Debrief>
Power Query limpia en el origen y recuerda cada paso. Esa es su gran ventaja frente a corregir datos a mano: el trabajo de limpieza se hace una vez y se repite solo cada vez que llegan datos nuevos.
</Debrief>

<Concepto>
Cuando una medida crece, repetir la misma parte varias veces la hace difícil de leer y de corregir. `VAR` guarda un resultado intermedio con un nombre, y `RETURN` indica qué devolver al final. Es como escribir la fórmula en pasos.

```text
Mi Medida =
VAR Paso1 = ...
VAR Paso2 = ...
RETURN Paso1 / Paso2
```

**Un ejemplo con la categoría.** El peso de Tecnologia sobre las ventas totales:

```text
% Tecnologia =
VAR VentasTec = CALCULATE(SUM(ventas[monto]), productos[categoria] = "Tecnologia")
VAR VentasTotal = SUM(ventas[monto])
RETURN DIVIDE(VentasTec, VentasTotal)
```

Se lee de arriba hacia abajo, como una receta, y si mañana cambia la definición de "ventas de tecnología", se corrige en un solo lugar.

**DIVIDE en vez de /.** `DIVIDE(a, b)` divide igual que `a / b`, pero si b es 0 o está vacío devuelve un valor en blanco en vez de un error. Una medida que divide puede quedar con el denominador en 0 cuando el visual filtra algo sin datos, y no debería romper el reporte.

**Formato de porcentaje.** El resultado es una proporción (0,509). Desde "Herramientas de medida", el formato Porcentaje lo muestra como 50,9 %.

**Práctica.**

1. Crea la medida % Ventas Norte: guarda en una variable las ventas del norte (con CALCULATE), en otra el total, y devuelve la división con DIVIDE.
2. Dale formato de porcentaje con un decimal.
3. Ponla en una tarjeta.
</Concepto>

<Debrief>
El norte representa el 50,9 % del monto, aunque tiene el 62,5 % de las ventas: vende más veces, pero productos más baratos. Con variables, la medida se lee como una explicación de ese cálculo.
</Debrief>

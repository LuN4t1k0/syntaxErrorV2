<Concepto>
A veces necesitas trabajar sobre un resumen, no sobre la tabla original: primero calcular algo por grupo y después filtrar, unir u ordenar ese resultado. Una subconsulta en `FROM` funciona como una tabla temporal hecha con otra consulta.

<Sintaxis lenguaje="sql" codigo={"SELECT r.columna\nFROM (SELECT ... GROUP BY ...) AS r\nWHERE r.columna > valor;"} />

**1. El resumen.** Escribe y ejecuta primero la consulta que agrupa.

<SqlEjemplo consulta={"SELECT estudiante_id, COUNT(*) AS cursos_tomados FROM inscripciones GROUP BY estudiante_id;"} />

**2. Usarlo como tabla.** Entre paréntesis, en el `FROM`, con un alias obligatorio. Desde afuera, sus columnas se leen como las de cualquier tabla: `r.cursos_tomados`.

<SqlEjemplo consulta={"SELECT r.estudiante_id, r.cursos_tomados\nFROM (SELECT estudiante_id, COUNT(*) AS cursos_tomados FROM inscripciones GROUP BY estudiante_id) AS r\nWHERE r.cursos_tomados >= 2;"} />

**3. Unirlo con otra tabla.** El resumen tiene ids; para mostrar nombres, se une con un `JOIN` como cualquier tabla.

<SqlEjemplo consulta={"SELECT e.nombre, r.cursos_tomados\nFROM (SELECT estudiante_id, COUNT(*) AS cursos_tomados FROM inscripciones GROUP BY estudiante_id) AS r\nJOIN estudiantes AS e ON e.id = r.estudiante_id\nWHERE r.cursos_tomados >= 2;"} />

**Otra forma de lo mismo.** Este filtro también se puede escribir con `GROUP BY` y `HAVING`. La subconsulta brilla cuando el resumen se vuelve a usar: unirlo con otra tabla, filtrarlo varias veces o resumirlo de nuevo. En la próxima lección verás `WITH`, que hace lo mismo y se lee mejor.
</Concepto>

<Debrief>
```sql
SELECT c.titulo, r.promedio
FROM (
  SELECT curso_id, ROUND(AVG(nota), 2) AS promedio
  FROM inscripciones
  GROUP BY curso_id
) AS r
JOIN cursos AS c ON c.id = r.curso_id
WHERE r.promedio >= 5.5;
```

Tres cursos llegan a 5.5: SQL inicial, Consultas avanzadas y Reportes con SQL, este último con 5.55 justo sobre el límite. Visualización de datos no aparece: su única inscripción todavía no tiene nota, y un promedio vacío no es mayor ni igual a nada.
</Debrief>

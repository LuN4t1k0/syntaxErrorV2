<Concepto>
Una subconsulta dentro de otra dentro de otra se vuelve difícil de leer. `WITH` resuelve eso: le pone nombre a un paso intermedio arriba de la consulta, y después lo usas como si fuera una tabla. A eso se le llama CTE (Common Table Expression).

<Sintaxis lenguaje="sql" codigo={"WITH nombre_paso AS (\n  SELECT ...\n)\nSELECT ... FROM nombre_paso;"} />

**Declarar el paso.** `WITH`, el nombre, `AS` y la consulta entre paréntesis. Después viene la consulta principal, que lo usa en su `FROM`.

<SqlEjemplo consulta={"WITH por_estado AS (\n  SELECT estado, COUNT(*) AS inscripciones\n  FROM inscripciones\n  GROUP BY estado\n)\nSELECT * FROM por_estado;"} />

**Filtrar y ordenar el resultado del paso.** En la consulta principal puedes usar `WHERE`, `ORDER BY` y `JOIN` sobre el CTE como sobre cualquier tabla.

<SqlEjemplo consulta={"WITH por_estado AS (\n  SELECT estado, COUNT(*) AS inscripciones\n  FROM inscripciones\n  GROUP BY estado\n)\nSELECT estado, inscripciones\nFROM por_estado\nWHERE inscripciones >= 2\nORDER BY inscripciones DESC;"} />

**Por qué no una subconsulta.** Hace lo mismo que la subconsulta en `FROM`, pero se lee de arriba hacia abajo, como una receta: primero calculo esto, después lo uso. Puedes declarar varios pasos separados por comas, y cada uno puede usar los anteriores. En consultas reales de varias etapas, es la forma más usada.
</Concepto>

<Debrief>
```sql
WITH por_ciudad AS (
  SELECT ciudad, COUNT(*) AS estudiantes, ROUND(AVG(edad), 1) AS edad_promedio
  FROM estudiantes
  GROUP BY ciudad
)
SELECT ciudad, estudiantes, edad_promedio
FROM por_ciudad
WHERE estudiantes >= 2
ORDER BY edad_promedio DESC;
```

Temuco tiene el estudiantado de mayor edad (24 años en promedio) y Concepción el más joven (21). La Serena queda fuera: con una sola persona, su "promedio" sería la edad de esa persona.
</Debrief>

<Concepto>
`CASE` crea una columna nueva a partir de reglas: "si la nota es 6 o más, 'destacado'; si es 4 o más, 'aprobado'; si no, 'reprobado'". Es el `if` de SQL, y sirve para segmentar sin tocar los datos.

<Sintaxis lenguaje="sql" codigo={"CASE\n  WHEN condición_1 THEN 'valor_1'\n  WHEN condición_2 THEN 'valor_2'\n  ELSE 'valor_por_defecto'\nEND AS nombre_columna"} />

**Se revisa en orden.** SQL prueba cada `WHEN` de arriba hacia abajo y usa el primero que se cumple; los siguientes ya no se miran. Por eso la segunda condición puede ser más simple: ya sabe que la primera no se cumplió.

<SqlEjemplo consulta={"SELECT titulo, horas,\n       CASE\n         WHEN horas < 20 THEN 'corto'\n         WHEN horas <= 30 THEN 'medio'\n         ELSE 'largo'\n       END AS duracion\nFROM cursos;"} />

**ELSE cubre el resto.** Todo lo que no cumplió ningún `WHEN` toma el valor del `ELSE`. Sin `ELSE`, esas filas quedan en `NULL`.

**Es una columna más.** Lleva alias, se puede ordenar y se puede agrupar: `GROUP BY` sobre una columna `CASE` cuenta cuántos hay en cada segmento.

**Ordenar con empates.** Si ordenas por una columna con valores repetidos, la base no garantiza en qué orden quedan las filas empatadas. Agrega una segunda columna al `ORDER BY` para desempatar.
</Concepto>

<SqlTask
  id="case-when"
  enunciado={"Clasifica a cada estudiante por edad en grupo_edad: 'junior' si tiene menos de 21 años, 'intermedio' si tiene entre 21 y 23 (ambos incluidos) y 'senior' si tiene más de 23. Muestra nombre, edad y grupo_edad, ordenados por edad y, si empatan, por nombre."}
  inicial={"SELECT nombre, edad FROM estudiantes ORDER BY edad, nombre;"}
  solucion={"SELECT nombre, edad, CASE WHEN edad < 21 THEN 'junior' WHEN edad <= 23 THEN 'intermedio' ELSE 'senior' END AS grupo_edad FROM estudiantes ORDER BY edad, nombre;"}
  comparar={"filas-en-orden"}
  pistas={["CASE revisa las condiciones en orden y se queda con la primera que se cumple.","Si la primera condición ya tomó a los menores de 21, la segunda solo necesita el límite de arriba.","Entre 21 y 23 \"ambos incluidos\": 23 es intermedio."]}
/>

<Debrief>
```sql
SELECT nombre, edad,
       CASE
         WHEN edad < 21 THEN 'junior'
         WHEN edad <= 23 THEN 'intermedio'
         ELSE 'senior'
       END AS grupo_edad
FROM estudiantes
ORDER BY edad, nombre;
```

El borde es el 23: con `edad < 23`, Martín Silva y Florencia Vera quedarían como senior. El `nombre` en el `ORDER BY` desempata a quienes tienen la misma edad, para que el orden sea siempre el mismo.
</Debrief>

<Concepto>
Cuando pegas datos en un asistente de IA, salen de tu organización y quedan en un servicio externo. Si incluyen nombres, RUT, correos o teléfonos, estás compartiendo datos personales, y en Chile la ley de protección de datos personales exige cuidarlos. La regla práctica: comparte solo lo que la tarea necesita.

**Tres herramientas.**
- **Minimizar:** quita las columnas que no hacen falta para la pregunta. Para clasificar reclamos por tema, el nombre y el correo del cliente no aportan.
- **Seudonimizar:** reemplaza el identificador por un código (C1, C2…). El mismo cliente recibe siempre el mismo código, así se puede seguir contando cuántos reclamos tiene cada uno sin saber quién es.
- **Usar una muestra:** para pedir una fórmula o un código basta con 5 a 10 filas, no con la tabla completa.

**En pandas.** `drop(columns=[...])` quita columnas. `factorize()` asigna un número a cada valor distinto de una columna, siempre el mismo para el mismo valor:

```python
codigos, _ = clientes["email"].factorize()
clientes["cliente_id"] = codigos + 1     # 1, 2, 3… el mismo número para el mismo email
```

**También en el texto libre.** Una descripción puede traer un teléfono o un nombre ("llámenme al 912345678"). Antes de compartirla, revísala o reemplaza esos patrones.

**Y siempre:** usa las herramientas de IA que tu organización autoriza, y pregunta antes de compartir datos de clientes.
</Concepto>

# Fase 3c2: Administración. Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dar a administración un panel en `/admin` para:
- gestionar usuarios (buscar, cambiar rol y eliminar cuentas por solicitud ARCO);
- ver el contenido y las métricas por misión (intentos, dónde se traban y abandono);
- moderar la comunidad (solicitudes docentes, comentarios de reseñas y reportes);
- supervisar las preguntas a docentes, las del tutor y su caché;
- revisar la bitácora de auditoría.

Además, que una cuenta eliminada o con el rol cambiado pierda al instante la sesión o los permisos anteriores en todos sus dispositivos.

**Architecture:**
- **Sesión siempre vigente (Task 1):**
  - El callback `jwt` de Auth.js llama a `refrescarToken`, que lee el usuario en la base en cada `auth()`.
  - Si la cuenta ya no existe, devuelve `null` y Auth.js descarta la sesión y borra la cookie. Lo verificamos en `@auth/core/lib/actions/session.js`.
  - Si existe, actualiza el rol del token.
  - Cuesta una consulta por clave primaria por request, y cierra el pendiente de las Fases 3a y 3c1.
- **Acceso a las páginas:**
  - Todas viven en `/admin` (grupo `(dashboard)`) y cada página llama a `adminDePagina()`: sin sesión va al login, y quien no es admin recibe 404.
  - El layout solo dibuja la navegación: no se confía en él para proteger datos, porque Next renderiza layout y página en paralelo.
- **Acceso a la API:** las rutas viven en `/api/admin/**` y usan `exigirAdmin()` (401/403). Todo id en la URL se valida como UUID antes de consultar.
- **Acciones de administración:**
  - Cada una deja registro en `audit_log`.
  - Se reutilizan las funciones de la Fase 3c1 (`decidirSolicitud`, `moderarComentario`, `crearMensaje` y `otorgarPuntos`). Esta fase agrega el aviso a la persona por mensaje interno y los puntos por un reporte útil.
- **Contenido:**
  - Casos y rutas se publican cambiando `estado` en `content/` y desplegando. Las páginas son estáticas y la sincronización del deploy pisa la base.
  - El panel muestra ese estado, cuántas personas se inscribieron y completaron, y las métricas por misión. No edita la publicación.
- **Listas:** se paginan de 25 en 25 con `?pagina=`. Un valor inválido se trata como la página 1.

**Tech Stack:** Next.js 15, React 19, Auth.js 5 (beta 31), Drizzle ORM 0.36, zod 3, Vitest 4, Playwright 1.55.

**Spec:** `docs/superpowers/specs/2026-09-29-syntaxerror-v2-design.md`. Secciones:
- 8: métricas por misión (intentos, dónde se traban, abandono);
- 9: Admin (usuarios, casos y rutas, métricas por misión y bitácora), Cuentas (eliminación y ARCO) y Comunidad;
- 12: permisos de admin;
- 16: Fase 3.

## Global Constraints

**Entorno**
- Todo se ejecuta en contenedores. Ningún paso corre `pnpm` o `node` en el host: se usa `docker compose run --rm tools ...`.
- Si los contenedores de la v1 (`cursos-*`) están arriba, ocupan los puertos 5432, 5433, 6379, 1025 y 8025. Detenlos antes con `docker compose -p cursos stop`.

**Texto y páginas**
- El texto visible va en español de Chile, con tildes y `¿`/`¡`, tratando de tú, sin voseo y con lenguaje neutro ("estudiante", "docente", "persona").
- Las páginas de misión y de caso siguen con `dynamic = "error"` y se sirven con `x-nextjs-cache: HIT`. Esta fase no las toca.

**Acceso**
- Cada página de `/admin` llama a `adminDePagina(ruta)` antes de leer datos.
- Cada ruta de `/api/admin` llama a `exigirAdmin()` y valida con `esUuid` los ids de la URL.
- Una persona admin no puede cambiar su propio rol ni eliminar su propia cuenta desde el panel.

**Datos**
- Toda acción de administración que cambia datos deja una entrada en `audit_log`, con quién la hizo, la IP y el user agent (`metaDeRequest`).
- Los emails y mensajes de esta fase se encolan con `encolarSinFallar`: si Redis no responde, la acción igual se completa.

**Tests y commits**
- Los tests de rutas mockean `@/lib/sesion` y `@/lib/emails`.

## Review Focus

1. **Cuenta eliminada con la sesión abierta en otro dispositivo, o rol cambiado mientras la persona navega.** En la siguiente request, `auth()` no devuelve sesión o devuelve el rol nuevo; no sirve el JWT viejo. Tests en Task 1 (unidad) y Task 7 (e2e: el admin elimina una cuenta y quien tenía la sesión abierta vuelve al login).
2. **Admin actuando sobre sí mismo.** No puede quitarse el rol ni eliminar su propia cuenta desde el panel: la API responde 400 y no cambia nada. Así nunca queda la plataforma sin admin por un clic. Test en Task 2.
3. **Búsqueda con `%`, `_` o `\`.** Se buscan literalmente, sin comodines ni errores de SQL. Test en Task 2.
4. **`?pagina=` inválido o fuera de rango** (`abc`, `-1`, `99999`). Devuelve la página 1 o una lista vacía con la paginación correcta, nunca un 500. Tests en Tasks 1 y 2.
5. **Dos admins, o un doble clic, resolviendo lo mismo.** Esto aplica al mismo reporte, a la misma solicitud o al mismo comentario: se resuelve una sola vez, con un solo mensaje y una sola suma de puntos, y la segunda request recibe 404. Test en Task 4.

```ts
import { eq } from "drizzle-orm";
import type { JWT } from "next-auth/jwt";
import type { DbClient } from "@syntaxerror/db/client";
import { users } from "@syntaxerror/db/schema";

// Cada auth() revisa la base: una cuenta eliminada pierde la sesión en todos sus dispositivos
// (devolver null hace que Auth.js descarte la sesión y borre la cookie) y un cambio de rol
// rige al instante, sin esperar que venza el JWT.
export async function refrescarToken(db: DbClient, token: JWT): Promise<JWT | null> {
  if (!token.sub) return token;
  const [fila] = await db.select({ role: users.role }).from(users).where(eq(users.id, token.sub));
  if (!fila) return null;
  return { ...token, role: fila.role };
}
```

export const TAMANO_PAGINA = 25;
const PAGINA_MAXIMA = 10_000;

export type Pagina<T> = { filas: T[]; total: number; pagina: number; paginas: number };

export function leerPagina(valor: string | string[] | undefined): number {
  const texto = Array.isArray(valor) ? valor[0] : valor;
  const numero = Number(texto);
  return Number.isInteger(numero) && numero >= 1 && numero <= PAGINA_MAXIMA ? numero : 1;
}

export function desplazamiento(pagina: number): number {
  return (pagina - 1) * TAMANO_PAGINA;
}

export function armarPagina<T>(filas: T[], total: number, pagina: number): Pagina<T> {
  return { filas, total, pagina, paginas: Math.max(1, Math.ceil(total / TAMANO_PAGINA)) };
}
```

import Link from "next/link";

export function Paginacion({ ruta, parametros, pagina, paginas }: { ruta: string; parametros: Record<string, string>; pagina: number; paginas: number }) {
  if (paginas <= 1) return null;
  const enlace = (numero: number) => `${ruta}?${new URLSearchParams({ ...parametros, pagina: String(numero) }).toString()}`;
  return (
    <nav aria-label="Paginación" className="flex items-center gap-4 text-sm font-bold">
      {pagina > 1 ? <Link className="text-primary hover:underline" href={enlace(pagina - 1)}>← Anterior</Link> : <span />}
      <span className="text-muted-foreground">{`Página ${Math.min(pagina, paginas)} de ${paginas}`}</span>
      {pagina < paginas ? <Link className="text-primary hover:underline" href={enlace(pagina + 1)}>Siguiente →</Link> : null}
    </nav>
  );
}

"use client";

import { useRouter } from "next/navigation";
import { useState } from "react";
import { Button } from "@syntaxerror/ui/components/button";
import { enviarJson } from "@/lib/cuenta/cliente";

type Props = {
  url: string;
  metodo?: "POST" | "PATCH" | "DELETE";
  cuerpo?: unknown;
  etiqueta: string;
  variante?: "primary" | "secondary" | "ghost" | "destructive";
  confirmar?: string;
};

export function BotonAccion({ url, metodo = "POST", cuerpo, etiqueta, variante = "secondary", confirmar }: Props) {
  const router = useRouter();
  const [enviando, setEnviando] = useState(false);
  const [error, setError] = useState<string | null>(null);

  async function ejecutar() {
    if (confirmar && !window.confirm(confirmar)) return;
    setEnviando(true);
    setError(null);
    const respuesta = await enviarJson(url, metodo, cuerpo);
    setEnviando(false);
    if (respuesta.ok) router.refresh();
    else setError(respuesta.status === 404 ? "Ya no está disponible: otra persona lo resolvió." : "No se pudo completar. Intenta de nuevo.");
  }

  return (
    <span className="inline-grid gap-1">
      <Button type="button" size="sm" variant={variante} disabled={enviando} onClick={ejecutar}>
        {etiqueta}
      </Button>
      {error ? <span role="status" className="text-xs font-bold">{error}</span> : null}
    </span>
  );
}
```

  - `type DetalleUsuario = FilaUsuario & { usuarioPublico; casos: CasoDelUsuario[]; nivel: Nivel; certificados: number }`;
  - `type Admin = { id: string; email: string }`.

  - `patronLiteral(texto)`;

  - `detalleUsuario(db, id): Promise<DetalleUsuario | null>`;
  - `cambiarRol(db, { admin, userId, rol }, meta)`, que devuelve `"ok" | "no_existe" | "propio"`;
  - `eliminarUsuario(db, { admin, userId, confirmacion }, { encolar, meta })`, que devuelve `"ok" | "no_existe" | "propio" | "confirmacion_incorrecta"`.

- Produces la API en `/api/admin/usuarios/[id]`:
  - `PATCH` recibe `{ rol }`;
  - `DELETE` recibe `{ confirmacion }`;
  - ambas responden 200, o 400 (`propio`, `confirmacion_incorrecta` o datos inválidos), 401, 403 o 404.
- Produces las páginas `/admin/usuarios?q=&pagina=` y `/admin/usuarios/[id]`.

import { count, desc, eq, ilike, or } from "drizzle-orm";
import type { AppDb } from "@syntaxerror/db/client";
import { insertAuditLogEntry } from "@syntaxerror/db/audit";
import { users } from "@syntaxerror/db/schema";
import { normalizeEmail } from "@/app/api/auth/register/service";
import { listarCertificados } from "@/lib/certificados/servicio";
import type { MetaRequest } from "@/lib/cuenta/meta";
import type { Encolar } from "@/lib/emails";
import { listarCasosDelUsuario, type CasoDelUsuario } from "@/lib/progreso/servicio";
import type { Nivel } from "@/lib/puntos/niveles";
import { obtenerNivel } from "@/lib/puntos/servicio";
import { esRol, type Rol } from "@/lib/roles";
import { armarPagina, desplazamiento, TAMANO_PAGINA, type Pagina } from "./paginacion";

export type FilaUsuario = { id: string; nombre: string | null; email: string; rol: Rol; verificado: boolean; creadoEn: Date };
export type DetalleUsuario = FilaUsuario & { usuarioPublico: string | null; casos: CasoDelUsuario[]; nivel: Nivel; certificados: number };
export type Admin = { id: string; email: string };

const columnas = {
  id: users.id,
  nombre: users.name,
  email: users.email,
  rol: users.role,
  emailVerificado: users.emailVerified,
  creadoEn: users.createdAt,
};

function aFila(fila: { id: string; nombre: string | null; email: string; rol: string; emailVerificado: Date | null; creadoEn: Date }): FilaUsuario {
  return {
    id: fila.id,
    nombre: fila.nombre,
    email: fila.email,
    rol: esRol(fila.rol) ? fila.rol : "student",
    verificado: fila.emailVerificado !== null,
    creadoEn: fila.creadoEn,
  };
}

// Los comodines de LIKE se escapan: buscar "ana_1" encuentra "ana_1" y no "anax1".
export function patronLiteral(texto: string): string {
  return `%${texto.replace(/[\\%_]/g, (caracter) => `\\${caracter}`)}%`;
}

export async function listarUsuarios(db: AppDb, { busqueda, pagina }: { busqueda?: string; pagina: number }): Promise<Pagina<FilaUsuario>> {
  const texto = busqueda?.trim();
  const filtro = texto ? or(ilike(users.email, patronLiteral(texto)), ilike(users.name, patronLiteral(texto))) : undefined;
  const [filas, [conteo]] = await Promise.all([
    db.select(columnas).from(users).where(filtro).orderBy(desc(users.createdAt), desc(users.id)).limit(TAMANO_PAGINA).offset(desplazamiento(pagina)),
    db.select({ total: count() }).from(users).where(filtro),
  ]);
  return armarPagina(filas.map(aFila), Number(conteo?.total ?? 0), pagina);
}

export async function detalleUsuario(db: AppDb, id: string): Promise<DetalleUsuario | null> {
  const [fila] = await db.select({ ...columnas, usuarioPublico: users.usuario }).from(users).where(eq(users.id, id));
  if (!fila) return null;
  const [casos, nivel, certificados] = await Promise.all([listarCasosDelUsuario(db, id), obtenerNivel(db, id), listarCertificados(db, id)]);
  return { ...aFila(fila), usuarioPublico: fila.usuarioPublico, casos, nivel, certificados: certificados.length };
}

// Desde el panel nadie cambia su propio rol: así la plataforma nunca queda sin admin por un clic.
export async function cambiarRol(
  db: AppDb,
  { admin, userId, rol }: { admin: Admin; userId: string; rol: Rol },
  meta: MetaRequest
): Promise<"ok" | "no_existe" | "propio"> {
  if (userId === admin.id) return "propio";
  return db.transaction(async (tx) => {
    const [actual] = await tx.select({ rol: users.role, email: users.email }).from(users).where(eq(users.id, userId)).for("update");
    if (!actual) return "no_existe";
    if (actual.rol === rol) return "ok";
    await tx.update(users).set({ role: rol, updatedAt: new Date() }).where(eq(users.id, userId));
    await insertAuditLogEntry(tx, {
      actorId: admin.id,
      actorEmail: admin.email,
      action: "role_changed",
      targetType: "user",
      targetId: userId,
      metadata: { rolAnterior: actual.rol, rolNuevo: rol, email: actual.email },
      ipAddress: meta.ip,
      userAgent: meta.userAgent,
    });
    return "ok";
  });
}

// Para solicitudes de eliminación (derechos ARCO) que llegan por otro canal. Se confirma escribiendo el email.
export async function eliminarUsuario(
  db: AppDb,
  { admin, userId, confirmacion }: { admin: Admin; userId: string; confirmacion: string },
  { encolar, meta }: { encolar: Encolar; meta: MetaRequest }
): Promise<"ok" | "no_existe" | "propio" | "confirmacion_incorrecta"> {
  if (userId === admin.id) return "propio";
  const [cuenta] = await db.select({ email: users.email, nombre: users.name }).from(users).where(eq(users.id, userId));
  if (!cuenta) return "no_existe";
  if (normalizeEmail(confirmacion) !== normalizeEmail(cuenta.email)) return "confirmacion_incorrecta";

  const eliminada = await db.transaction(async (tx) => {
    const filas = await tx.delete(users).where(eq(users.id, userId)).returning({ id: users.id });
    if (filas.length === 0) return false;
    await insertAuditLogEntry(tx, {
      actorId: admin.id,
      actorEmail: admin.email,
      action: "account_deleted",
      targetType: "user",
      targetId: userId,
      metadata: { porAdmin: true, email: cuenta.email },
      ipAddress: meta.ip,
      userAgent: meta.userAgent,
    });
    return true;
  });
  if (!eliminada) return "no_existe";
  await encolar({ tipo: "cuenta-eliminada", para: cuenta.email, nombre: cuenta.nombre });
  return "ok";
}

import { NextResponse } from "next/server";
import { z } from "zod";
import { getDb } from "@syntaxerror/db/client";
import { cambiarRol, eliminarUsuario } from "@/lib/admin/usuarios";
import { metaDeRequest } from "@/lib/cuenta/meta";
import { encolarSinFallar } from "@/lib/emails";
import { exigirAdmin } from "@/lib/permisos";
import { ROLES } from "@/lib/roles";
import { esUuid } from "@/lib/uuid";

const rolSchema = z.object({ rol: z.enum(ROLES) });
const eliminarSchema = z.object({ confirmacion: z.string().min(1).max(320) });
type Parametros = { params: Promise<{ id: string }> };

const noExiste = () => NextResponse.json({ error: "no_existe" }, { status: 404 });

export async function PATCH(request: Request, { params }: Parametros) {
  const { usuario, error } = await exigirAdmin();
  if (error) return error;
  const { id } = await params;
  if (!esUuid(id)) return noExiste();
  const parsed = rolSchema.safeParse(await request.json().catch(() => null));
  if (!parsed.success) return NextResponse.json({ error: "datos_invalidos" }, { status: 400 });
  const resultado = await cambiarRol(getDb(), { admin: usuario, userId: id, rol: parsed.data.rol }, metaDeRequest(request));
  if (resultado === "no_existe") return noExiste();
  if (resultado === "propio") return NextResponse.json({ error: "propio" }, { status: 400 });
  return NextResponse.json({ ok: true });
}

export async function DELETE(request: Request, { params }: Parametros) {
  const { usuario, error } = await exigirAdmin();
  if (error) return error;
  const { id } = await params;
  if (!esUuid(id)) return noExiste();
  const parsed = eliminarSchema.safeParse(await request.json().catch(() => null));
  if (!parsed.success) return NextResponse.json({ error: "datos_invalidos" }, { status: 400 });
  const resultado = await eliminarUsuario(
    getDb(),
    { admin: usuario, userId: id, confirmacion: parsed.data.confirmacion },
    { encolar: encolarSinFallar, meta: metaDeRequest(request) }
  );
  if (resultado === "no_existe") return noExiste();
  if (resultado !== "ok") return NextResponse.json({ error: resultado }, { status: 400 });
  return NextResponse.json({ ok: true });
}

import { and, asc, avg, count, eq, ne, sql } from "drizzle-orm";
import type { AppDb } from "@syntaxerror/db/client";
import { casoInscripciones, casos, misionProgreso, rutaCasos, rutas } from "@syntaxerror/db/schema";

export const DIAS_ABANDONO = 14;

export type FilaContenido = { slug: string; titulo: string; rutas: { slug: string; titulo: string; estado: string }[]; inscritos: number; completados: number };
export type MetricaMision = {
  slug: string;
  titulo: string;
  iniciaron: number;
  aprobaron: number;
  tasaAprobacion: number;
  intentosPromedio: number;
  abandonos: number;
  trabas: { tarea: string; estudiantes: number }[];
};
export type MetricasCaso = { caso: { slug: string; titulo: string }; misiones: MetricaMision[] };

export async function resumenContenido(db: AppDb): Promise<FilaContenido[]> {
  const [listaCasos, enlaces, conteos] = await Promise.all([
    db.select({ id: casos.id, slug: casos.slug, titulo: casos.titulo }).from(casos).orderBy(asc(casos.titulo)),
    db
      .select({ casoId: rutaCasos.casoId, slug: rutas.slug, titulo: rutas.titulo, estado: rutas.estado })
      .from(rutaCasos)
      .innerJoin(rutas, eq(rutas.id, rutaCasos.rutaId))
      .orderBy(asc(rutas.titulo)),
    db
      .select({ casoId: casoInscripciones.casoId, inscritos: count(), completados: count(casoInscripciones.completadoEn) })
      .from(casoInscripciones)
      .groupBy(casoInscripciones.casoId),
  ]);
  return listaCasos.map((caso) => {
    const conteo = conteos.find((fila) => fila.casoId === caso.id);
    return {
      slug: caso.slug,
      titulo: caso.titulo,
      rutas: enlaces.filter((enlace) => enlace.casoId === caso.id).map(({ slug, titulo, estado }) => ({ slug, titulo, estado })),
      inscritos: Number(conteo?.inscritos ?? 0),
      completados: Number(conteo?.completados ?? 0),
    };
  });
}

export async function metricasDeCaso(db: AppDb, casoSlug: string, ahora = new Date()): Promise<MetricasCaso | null> {
  const [caso] = await db.select({ id: casos.id, slug: casos.slug, titulo: casos.titulo, misiones: casos.misiones }).from(casos).where(eq(casos.slug, casoSlug));
  if (!caso) return null;
  const limite = new Date(ahora.getTime() - DIAS_ABANDONO * 86_400_000).toISOString();

  const [agregados, enCurso] = await Promise.all([
    db
      .select({
        mision: misionProgreso.mision,
        iniciaron: count(),
        aprobaron: sql<string>`count(*) filter (where ${misionProgreso.estado} = 'aprobada')`,
        intentos: avg(misionProgreso.intentos),
        abandonos: sql<string>`count(*) filter (where ${misionProgreso.estado} <> 'aprobada' and ${misionProgreso.actualizadoEn} < ${limite}::timestamptz)`,
      })
      .from(misionProgreso)
      .where(eq(misionProgreso.casoId, caso.id))
      .groupBy(misionProgreso.mision),
    db
      .select({ mision: misionProgreso.mision, tareasAprobadas: misionProgreso.tareasAprobadas })
      .from(misionProgreso)
      .where(and(eq(misionProgreso.casoId, caso.id), ne(misionProgreso.estado, "aprobada"))),
  ]);

  const misiones = caso.misiones.map((mision) => {
    const fila = agregados.find((agregado) => agregado.mision === mision.slug);
    const iniciaron = Number(fila?.iniciaron ?? 0);
    const aprobaron = Number(fila?.aprobaron ?? 0);
    // Cada estudiante con la misión en curso cuenta en la primera tarea que le falta.
    const porTarea = new Map<string, number>();
    for (const progreso of enCurso) {
      if (progreso.mision !== mision.slug) continue;
      const tarea = mision.tareas.find((candidata) => !progreso.tareasAprobadas.includes(candidata));
      if (tarea) porTarea.set(tarea, (porTarea.get(tarea) ?? 0) + 1);
    }
    const trabas = [...porTarea]
      .map(([tarea, estudiantes]) => ({ tarea, estudiantes }))
      .sort((a, b) => b.estudiantes - a.estudiantes || mision.tareas.indexOf(a.tarea) - mision.tareas.indexOf(b.tarea));
    return {
      slug: mision.slug,
      titulo: mision.titulo,
      iniciaron,
      aprobaron,
      tasaAprobacion: iniciaron > 0 ? Math.round((aprobaron / iniciaron) * 100) / 100 : 0,
      intentosPromedio: fila?.intentos ? Math.round(Number(fila.intentos) * 10) / 10 : 0,
      abandonos: Number(fila?.abandonos ?? 0),
      trabas,
    };
  });
  return { caso: { slug: caso.slug, titulo: caso.titulo }, misiones };
}

export async function resolverSolicitudDocente(
  db: AppDb,
  { solicitudId, admin, decision }: { solicitudId: string; admin: Admin; decision: "aprobada" | "rechazada" },
  { encolar, meta }: Dependencias
): Promise<boolean> {
  const [solicitud] = await db.select({ userId: solicitudesDocente.userId }).from(solicitudesDocente).where(eq(solicitudesDocente.id, solicitudId));
  if (!solicitud) return false;
  if (!(await decidirSolicitud(db, { solicitudId, admin, decision }, meta))) return false;
  await insertAuditLogEntry(db, {

    actorEmail: admin.email,

    targetType: "teacher_request",
    targetId: solicitudId,
    metadata: { decision },
    ipAddress: meta.ip,
    userAgent: meta.userAgent,
  });
  const aprobada = decision === "aprobada";
  await crearMensaje(
    db,
    {
      userId: solicitud.userId,
      remitenteId: admin.id,
      asunto: aprobada ? "Tu acceso docente fue aprobado" : "Revisamos tu solicitud de acceso docente",
      cuerpo: aprobada
        ? "Ya puedes crear clases, compartir su código y responder las preguntas de tus estudiantes desde tu panel docente, en /profesor."

export async function listarReportes(db: AppDb, { estado, pagina }: { estado: "pendiente" | "resuelto"; pagina: number }): Promise<Pagina<FilaReporte>> {
  const filtro = eq(reportes.estado, estado);
  const [filas, [conteo]] = await Promise.all([
    db
      .select({
        id: reportes.id,
        tipo: reportes.tipo,
        descripcion: reportes.descripcion,
        pagina: reportes.pagina,
        estado: reportes.estado,
        nombre: users.name,
        email: users.email,
        creadoEn: reportes.creadoEn,
        resueltoEn: reportes.resueltoEn,
      })
      .from(reportes)
      .innerJoin(users, eq(users.id, reportes.userId))
      .where(filtro)
      .orderBy(estado === "pendiente" ? asc(reportes.creadoEn) : desc(reportes.resueltoEn))
      .limit(TAMANO_PAGINA)
      .offset(desplazamiento(pagina)),
    db.select({ total: count() }).from(reportes).where(filtro),
  ]);

    filas.map(({ nombre, email, ...fila }) => ({ ...fila, autor: { nombre, email } })),
    Number(conteo?.total ?? 0),

  );
}

export async function resolverReporte(
  db: AppDb,
  { reporteId, admin, util, respuesta }: { reporteId: string; admin: Admin; util: boolean; respuesta: { asunto: string; cuerpo: string } | null },
  { encolar, meta }: Dependencias
): Promise<boolean> {
  // Solo resuelve si sigue pendiente: de dos clics o dos admins, solo uno avisa y suma puntos.
  const [reporte] = await db
    .update(reportes)
    .set({ estado: "resuelto", resueltoPor: admin.id, resueltoEn: new Date() })
    .where(and(eq(reportes.id, reporteId), eq(reportes.estado, "pendiente")))
    .returning({ userId: reportes.userId, tipo: reportes.tipo, caso: reportes.caso });
  if (!reporte) return false;

  await insertAuditLogEntry(db, {
    actorId: admin.id,
    actorEmail: admin.email,
    action: "report_resolved",
    targetType: "report",
    targetId: reporteId,
    metadata: { util, respondido: respuesta !== null },
    ipAddress: meta.ip,
    userAgent: meta.userAgent,
  });
  if (util && reporte.tipo === "error" && reporte.caso) {
    const [caso] = await db.select({ id: casos.id }).from(casos).where(eq(casos.slug, reporte.caso));
    if (caso) {
      await otorgarPuntos(db, { userId: reporte.userId, casoId: caso.id, clave: `reporte:${reporteId}`, motivo: "reporte_util", cantidad: PUNTOS_REPORTE_UTIL });
    }

export function FormularioReporteAdmin({ reporteId, esError }: { reporteId: string; esError: boolean }) {
  const router = useRouter();

    evento.preventDefault();
    void resolver(true);

// Borrar una respuesta mala de la caché hace que la próxima pregunta parecida vuelva a pasar por la IA.
export async function borrarRespuestaCache(db: AppDb, { id, admin }: { id: string; admin: Admin }, meta: MetaRequest): Promise<boolean> {
  return db.transaction(async (tx) => {
    const [entrada] = await tx
      .select({ pregunta: tutorCache.pregunta, mision: tutorCache.mision, caso: casos.slug })
      .from(tutorCache)
      .innerJoin(casos, eq(casos.id, tutorCache.casoId))
      .where(eq(tutorCache.id, id));
    if (!entrada) return false;
    const borradas = await tx.delete(tutorCache).where(eq(tutorCache.id, id)).returning({ id: tutorCache.id });
    if (borradas.length === 0) return false;
    await insertAuditLogEntry(tx, {
      actorId: admin.id,
      actorEmail: admin.email,
      action: "tutor_cache_deleted",
      targetType: "tutor_cache",
      targetId: id,
      metadata: { caso: entrada.caso, mision: entrada.mision, pregunta: entrada.pregunta },
      ipAddress: meta.ip,
      userAgent: meta.userAgent,
    });
    return true;
  });
}

export async function DELETE(request: Request, { params }: { params: Promise<{ id: string }> }) {
  const { usuario, error } = await exigirAdmin();
  if (error) return error;
  const { id } = await params;

  }

}

import { and, count, desc, eq, ilike, type SQL } from "drizzle-orm";
import type { AppDb } from "@syntaxerror/db/client";
import type { AuditAction } from "@syntaxerror/db/audit";
import { auditLog } from "@syntaxerror/db/schema";
import { armarPagina, desplazamiento, TAMANO_PAGINA, type Pagina } from "./paginacion";
import { patronLiteral } from "./usuarios";

export type FilaBitacora = {
  id: string;
  creadoEn: Date;
  accion: string;
  actorEmail: string | null;
  destino: string | null;
  destinoId: string | null;
  metadata: Record<string, unknown>;
  ip: string | null;
};

export async function listarBitacora(
  db: AppDb,
  { accion, email, pagina }: { accion?: AuditAction; email?: string; pagina: number }
): Promise<Pagina<FilaBitacora>> {
  const condiciones: SQL[] = [];
  if (accion) condiciones.push(eq(auditLog.action, accion));
  const texto = email?.trim();
  if (texto) condiciones.push(ilike(auditLog.actorEmail, patronLiteral(texto)));
  const filtro = condiciones.length > 0 ? and(...condiciones) : undefined;
  const [filas, [conteo]] = await Promise.all([
    db
      .select({
        id: auditLog.id,
        creadoEn: auditLog.createdAt,
        accion: auditLog.action,
        actorEmail: auditLog.actorEmail,
        destino: auditLog.targetType,
        destinoId: auditLog.targetId,
        metadata: auditLog.metadata,
        ip: auditLog.ipAddress,
      })
      .from(auditLog)
      .where(filtro)
      .orderBy(desc(auditLog.createdAt), desc(auditLog.id))
      .limit(TAMANO_PAGINA)
      .offset(desplazamiento(pagina)),
    db.select({ total: count() }).from(auditLog).where(filtro),
  ]);
  return armarPagina(filas, Number(conteo?.total ?? 0), pagina);
}

import type { AppDb } from "@syntaxerror/db/client";
import { preguntasProfesor, reportes, resenasCaso, solicitudesDocente, tutorPreguntas, users } from "@syntaxerror/db/schema";

export type ResumenAdmin = {
  usuarios: number;
  nuevosSemana: number;
  docentes: number;
  solicitudesPendientes: number;
  comentariosPendientes: number;
  reportesPendientes: number;
  preguntasSinDocente: number;

export async function resumenAdmin(db: AppDb, ahora = new Date()): Promise<ResumenAdmin> {
  const semana = new Date(ahora.getTime() - 7 * 86_400_000);
  const total = async (consulta: Promise<{ total: number }[]>) => Number((await consulta)[0]?.total ?? 0);
  const [usuarios, nuevosSemana, docentes, solicitudesPendientes, comentariosPendientes, reportesPendientes, preguntasSinDocente, preguntasTutorSemana] =
    await Promise.all([
      total(db.select({ total: count() }).from(users)),
      total(db.select({ total: count() }).from(users).where(gte(users.createdAt, semana))),
      total(db.select({ total: count() }).from(users).where(eq(users.role, "teacher"))),
      total(db.select({ total: count() }).from(solicitudesDocente).where(eq(solicitudesDocente.estado, "pendiente"))),
      total(db.select({ total: count() }).from(resenasCaso).where(eq(resenasCaso.estadoComentario, "pendiente"))),
      total(db.select({ total: count() }).from(reportes).where(eq(reportes.estado, "pendiente"))),
      total(db.select({ total: count() }).from(preguntasProfesor).where(and(eq(preguntasProfesor.estado, "pendiente"), isNull(preguntasProfesor.profesorId)))),
      total(db.select({ total: count() }).from(tutorPreguntas).where(gte(tutorPreguntas.creadoEn, semana))),
    ]);
  return { usuarios, nuevosSemana, docentes, solicitudesPendientes, comentariosPendientes, reportesPendientes, preguntasSinDocente, preguntasTutorSemana };
}
